# Vida RPG

PWA personal para convertir hábitos, entrenamiento, trabajo y progreso personal en un sistema de personaje tipo RPG.

## Incluye

- Perfil con foto, nivel general y rango.
- Atributos: Intelecto, Carisma, Rendimiento y Físico.
- Tareas diarias con checkbox y XP.
- Tareas personales con categoría y XP configurable.
- Check-in de sueño, energía, ánimo y notas.
- Registro de fuerza para seis ejercicios.
- Rachas y logros.
- Instalación como PWA.
- Recordatorios mientras la app está activa.

## Notificaciones

La versión actual puede mostrar recordatorios cuando la PWA está activa. Para notificaciones push confiables con la app completamente cerrada se necesita un backend/push service (por ejemplo Firebase/FCM o Supabase + Web Push).

## Publicación

El repositorio incluye un workflow de GitHub Pages en `.github/workflows/pages.yml`.
